# ITA1414-Ethical-Hacking
# Ethical Hacking Lab – Linux Basics (Experiments 1–5)

## Overview

This repository contains the practical exercises performed as part of the Ethical Hacking Laboratory using Kali Linux. The experiments focus on learning fundamental Linux commands for file handling, directory management, file viewing, text editing, and obtaining system information. These basic commands are essential for ethical hacking, penetration testing, and Linux system administration.

---

# Software Requirements

- Oracle VirtualBox
- Kali Linux 2025.4
- Bash Terminal

---

# Experiment 1 – File Creation and Deletion

## Aim
To learn basic file creation and deletion commands.

### Commands Used

```bash
vim
rm
ls
ll
tree
users
```

### Tasks Performed

- Created text files
- Listed files using `ls` and `ll`
- Deleted files using `rm`
- Viewed logged-in users
- Displayed directory structure using `tree`

### Learning Outcome

- Creating files
- Deleting files
- Listing directory contents
- Understanding Linux file structure

# Linux Commands Practiced

| Command | Description |
|----------|-------------|
| ls | Lists files and directories |
| ll | Detailed directory listing |
| tree | Displays directory structure |
| vim | Creates and edits files |
| less | Views file contents page-wise |
| more | Displays file contents |
| head | Shows first 10 lines |
| tail | Shows last 10 lines |
| mkdir | Creates directories |
| rm | Removes files |
| mv | Renames or moves files |
| users | Displays logged-in users |
| uptime | Displays system uptime |
| date | Displays current date and time |
